Entorno de Producción v1.0

Sistema Integrador Orientado a Servicios

Plataforma en producción para la gestión de usuarios mediante servicios RESTful (Jakarta Servlet) y aplicación móvil Android nativa.

Ver Repositorio Oficial

Módulo Móvil Android

Interfaz móvil validada con pruebas unitarias JUnit 4 para registro, consulta y eliminación de usuarios por ID.

API de Servicios Web

Endpoints HTTP configurados para procesar peticiones GET, POST y DELETE en formato JSON.

Base de Datos

Estructura relacional MySQL aprovisionada para garantizar la persistencia y trazabilidad de registros.
